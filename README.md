# ZAUM Creators

Небольшой демонстрационный сервис для ежедневной работы с базой блогеров и рекламными размещениями. Данные взяты из копии исходной таблицы ZAUM; в исходнике находятся только вымышленные демонстрационные записи.

## Возможности

- Обзор записей, статусов, площадок, бюджета и среднего CPM.
- Каталог с поиском по данным, фильтрами, сортировкой и подробными карточками.
- Добавление, редактирование, смена статуса и удаление записей.
- Экспорт базы в CSV.
- Адаптивный интерфейс для компьютера и телефона.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Production-сборка и локальный предпросмотр:

```bash
npm run build
npm run preview
```

## Данные

Исходные демонстрационные выгрузки сохранены в `data/ZAUM_demo.csv` и `data/ZAUM_demo.xlsx`. Приложение импортирует подготовленный JSON в `src/data/creators.json` и не подключается к Google Sheets. Пользовательские изменения сохраняются в `localStorage` браузера и остаются в этом браузере на этом устройстве. Команда `Сбросить данные` не предусмотрена: для возврата к исходной базе очистите данные сайта в настройках браузера.

Средний CPM считается средним значением исходного столбца CPM; при создании или редактировании записи он рассчитывается как стоимость размещения, делённая на охват сторис, умноженная на 1000. Количество записей в работе — все статусы, кроме «Результаты получены». В исходной таблице отсутствует история изменений.

## Технологии

React, TypeScript, Vite, Recharts и Lucide React. Хранилище — localStorage без сервера и учётных записей.
